# KNN Classification – Early ML Exploration

This project is an exploratory Jupyter Notebook implementing a **K-Nearest Neighbors (KNN)** classifier on a banking dataset.

It represents early experimentation with machine learning concepts, data preprocessing, and model training using Python.

---

## Purpose

The goal of this notebook was to:

- Practice loading and inspecting real-world datasets
- Encode categorical variables for machine learning
- Build feature vectors
- Apply a basic supervised learning algorithm (KNN)
- Understand the end-to-end ML workflow at a foundational level

This is a **learning-focused project**, not a production-ready system.

---

## Dataset

- Dataset: `bank.csv`
- Source: Banking marketing data
- Format: CSV with categorical and numerical features

The dataset includes attributes such as:

- Job
- Marital status
- Education
- Housing loan
- Contact method
- Campaign outcome
- Subscription result (`yes` / `no`)
